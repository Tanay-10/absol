Trajectory Schema Structure

How should the JSONB column be shaped? Pick the approach that feels most natural to work with.

A — Waypoint List

Recommended

Each waypoint is a self-contained object with timestamp, position, and state. Most readable, easy for frontend to iterate, interpolation is trivial.

{
  "waypoints": [
    {
      "t": "2026-04-23T12:00:00Z",
      "lat": 25.5,
      "lon": -85.2,
      "state": {
        "intensity": 85,
        "speed_kph": 45,
        "direction_deg": 320,
        "category": 3,
        "radius_km": 120
      }
    },
    { "t": "2026-04-23T13:00:00Z",
      "lat": 26.1, "lon": -85.8,
      "state": { "intensity": 90, ... }
    }
  ],
  "interval_minutes": 60,
  "current_index": 5,
  "total_waypoints": 24
}

Pros

  • Self-documenting
  • Easy interpolation
  • Add/remove fields freely

Cons

  • Slightly more bytes per record

B — Parallel Arrays

Timestamps, coordinates, and property arrays stored in parallel. Compact, but harder to read and error-prone if arrays get out of sync.

{
  "timestamps": [
    "2026-04-23T12:00:00Z",
    "2026-04-23T13:00:00Z"
  ],
  "coordinates": [
    [25.5, -85.2],
    [26.1, -85.8]
  ],
  "properties": [
    { "intensity": 85, "category": 3 },
    { "intensity": 90, "category": 4 }
  ],
  "current_index": 5
}

Pros

  • Smaller payload size
  • Array-slice friendly

Cons

  • Arrays must stay in sync
  • Harder to read/debug

C — GeoJSON FeatureCollection

Standard GeoJSON format with timestamped Point features. Compatible with mapping libraries directly, but verbose and adds nesting with little gain for this use case.

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [-85.2, 25.5]
      },
      "properties": {
        "time": "2026-04-23T12:00:00Z",
        "intensity": 85,
        "category": 3
      }
    }
  ],
  "current_index": 5
}

Pros

  • GeoJSON standard
  • Some libs accept directly

Cons

  • Very verbose
  • Extra nesting
  • Overkill for hackathon
